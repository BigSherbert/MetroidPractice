Initial release of Grand Marais v1.0.
This game was made as practice for learning Game Development using Godot 4.7.1.
It mimics the game-play of the classic Metroid games.

This release contains:
-A simple executable (.exe) file that can be run on computers using a modern Windows operating system.
-A x86_64 file for Linux users.

Note that these files will be unsigned in Windows so Windows may not recognize the files, however you can still run them safely by following the prompts.
